
# 1thing Release Notes

## 1.9 "Taarnet"

### Changes

- Added a Clear command to the menu bar context menu.
- Automatic now uses the Light profile in Light Mode and the Dark profile in Dark Mode.
- Renamed the Bright profile to Light.

---

## 1.8 "Taarnet"

### Changes

- Reduced horizontal padding around the menu bar text.
- Made icon hover animations in the editor smoother and slightly slower.
- Profile colors can now be changed without selecting the corresponding profile first.

---

## 1.7.5 "Taarnet"

### Changes

- Increased contrast of the History and Clear buttons.
- Increased Color Well height.
- Reduced bottom padding for a more compact layout.

### New Features

- Added keyboard shortcuts:
  - ⌘1–⌘4 to switch display profiles
  - ⌘B for bold text
  - ⌘I for italic text
- Display profile shortcuts are now shown in the context menu.

---

## 1.7.4 "Taarnet"

### Changes

- Character limit stepper now changes in steps of 10.
- Maximum character limit reduced to 150 characters.

---

## 1.7.3 "Taarnet"

### Fixes

- Increased width of the character limit field so three-digit values are fully visible.

---

## 1.7.2 "Taarnet"

### Fixes

- Fixed a layout issue where selecting another profile could expand the popup width.
- Improved popover layout stability.

---

## 1.7.1 "Taarnet"

### Changes

- Slower and smoother hover animations.
- Character limit controls moved next to the text style buttons.
- Removed tooltips from popup controls for a cleaner interface.

---

## 1.7.0 "Taarnet"

### Changes

- Refined popup layout.
- Automatic profile moved to the right in the profile selector.
- Flatter color wells positioned directly beneath their corresponding profile buttons.
- Improved hover effects throughout the interface.
- Larger character limit field.
- Numerous spacing and alignment improvements.

---

## 1.6.0 "Taarnet"

### New

- Completely redesigned settings popup.
- Compact multi-row layout.
- Four dedicated display profiles.
- Individual colors for every profile.
- Inline text style controls.
- Adjustable character limit.
- Reminder history.
- Improved native macOS appearance.

---

## Earlier Versions

Earlier releases introduced the core functionality of 1thing, including:

- menu bar reminder
- editable reminder popup
- rich text rendering
- automatic menu bar updates
- profile support
- native macOS integration
